# ⚡ PokeSearch

Una aplicación educativa hecha con **React + TailwindCSS** que permite buscar Pokémon utilizando la **PokeAPI**.

## 🚀 Tecnologías
- React
- React Router DOM
- TailwindCSS
- React Hook Form
- Context API
- PokeAPI (https://pokeapi.co/)

## 🌈 Características
- Buscar Pokémon por nombre o ID.
- Mostrar nombre, ID, tipos e imagen.
- Modo oscuro / claro persistente.
- Responsive y accesible.
- Componentes reutilizables y hooks personalizados.

## 🧠 Hooks personalizados
- `useTheme` → controla el modo oscuro/claro.
- `usePokemon` → obtiene Pokémon desde la API.
