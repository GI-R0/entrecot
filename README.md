# PokeSearch

Proyecto educativo realizado con **React** y **TailwindCSS** para explorar Pokémon usando la **API pública de PokeAPI**.

---

## 📚 Descripción

PokeSearch permite:

- Explorar la Pokédex con lista de Pokémon.
- Buscar Pokémon por nombre o ID.
- Visualizar información detallada de cada Pokémon.
- Cambiar entre **tema claro y oscuro**.
- Navegar entre páginas principales: Inicio, Buscar y Acerca.

Este proyecto demuestra el uso de **React**, **React Router**, **Hooks personalizados**, **Context API**, **formularios con react-hook-form** y **fetch a APIs externas
